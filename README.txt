FPL Pocket - ملفات مسطحة بدون مجلدات

الملفات:
- index.html: التطبيق بالكامل
- manifest.webmanifest: إعداد تثبيت PWA
- sw.js: تشغيل أساسيات التطبيق دون اتصال
- icon.svg: أيقونة التطبيق

النشر على Vercel:
1) ارفع الملفات الأربعة في جذر مستودع GitHub (وليس داخل أي مجلد).
2) في Vercel اختر Framework Preset: Other.
3) اترك Build Command فارغًا.
4) اترك Output Directory فارغًا أو استخدم الإعداد الافتراضي لجذر المشروع.
5) اضغط Deploy.

ملاحظات:
- التطبيق لا يحتاج package.json أو مجلد api.
- يقرأ بيانات FPL من الواجهة العامة الرسمية مباشرة من المتصفح. إذا منع المتصفح طلبات API أو تغيرت سياسة CORS فقد لا يتم التحميل.
- التحديث التلقائي كل دقيقة يعمل أثناء فتح التطبيق فقط.
- تنبيهات الأحداث تعمل أثناء فتح التطبيق فقط؛ تنبيهات الخلفية عند إغلاق التطبيق تحتاج خدمة خلفية منفصلة.
- لا توجد حاجة لإدخال كلمة مرور FPL؛ المطلوب Team ID فقط.
